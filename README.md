# Румбы ветра — фронтенд

SPA для оценки влияния направления ветра на время полёта Boeing-737 NG Лондон–Париж.
Роли — гость и диспетчер (вошедший пользователь).

## Ссылки

- **Бэкенд:** https://github.com/itisneutro/rhumbs-backend
- **GitHub Pages:** появится в ЛР-7

## Стек

React 19.2.8, TypeScript 6.0.2, Vite 8.3.0, React-Bootstrap 2.10.10, React Router 7.18.4, Redux Toolkit 2.14.0, axios 1.21.1, swagger-typescript-api 13.14.0.

## Структура проекта

| Папка/файл | Назначение |
|---|---|
| `src/pages` | страницы «Лента», «Добавление», «Плитка», «Вход» |
| `src/components` | нижняя панель, фильтр, карточка румба, роза румбов |
| `src/slices` | слайсы Redux: румбы с thunk и пользователь |
| `src/api` | клиент axios, сгенерированный из Swagger (`Api.ts` — не править руками), и экземпляр `api` |
| `src/modules` | mock-данные, типы и преобразование адресов медиа |
| `src/styles` | стили приложения `rhumbs.css` |
| `public` | заглушки изображения и видео, mock-файлы `rhumbs-mock` |
| `scripts/generate-api.mjs` | кодогенерация `src/api/Api.ts` из Swagger бэкенда |
| `vite.config.ts` | настройки Vite и прокси `/api`, `/minio` |

## Страницы

### «Лента»

- **Маршрут:** `/rhumbs/feed` — первый румб, `/rhumbs/feed/:id` — румб с этим id
- **Поля:** видео, название, описание, роза румбов, азимуты «Географический» и «Магнитный»,
  число лайков
- **Кнопки:** «Ещё» / «Свернуть» — раскрыть и свернуть описание; лайк — сердце с числом
  лайков; круглая кнопка со стрелкой (`aria-label="Следующий"`) — следующий румб по кругу
- **Гость:** смотрит ленту, лайк неактивен
- **Диспетчер:** ставит и снимает лайк

### «Добавление»

- **Маршрут:** `/rhumbs/draft`
- **Поля:** превью изображения и видео (без файла — `rhumbs-default.jpg` и
  `rhumbs-default.mp4`), «Название»; когда черновик есть — превью из черновика и ещё
  «Краткое описание», «Географический азимут» (0–359, шаг 1), «Магнитный азимут»
  (0–359.9, шаг 0.1)
- **Кнопки:** «Выбрать» на превью (пока черновика нет); «Далее» — создать черновик;
  «Опубликовать» — опубликовать румб и перейти на «Плитку»
- **Гость:** страница недоступна, переход на «Плитку»
- **Диспетчер:** создаёт и публикует румб

### «Плитка»

- **Маршрут:** `/rhumbs`
- **Поля:** фильтр — «Азимут от», слайдер от 0 до 315 с шагом 45 и значение в градусах;
  карточки в 2 колонки — изображение, название, роза румбов, азимуты «Географический» и
  «Магнитный», число лайков
- **Кнопки:** «Найти» — румбы с географическим азимутом не меньше выбранного; клик по
  карточке — лента с этого румба; «Удалить» на карточке
- **Гость:** смотрит и фильтрует румбы
- **Диспетчер:** ещё удаляет свои румбы — «Удалить» есть только на них

### «Вход»

- **Маршрут:** `/rhumbs/login`
- **Поля:** «Логин», «Пароль»
- **Кнопки:** «Войти» — вход и переход на «Плитку»; при ошибке у полей красная рамка
- **Гость:** входит и становится диспетчером, регистрации нет
- **Диспетчер:** в нижней панели вместо «Вход» — «Выход»

### Нижняя панель

| Пункт | Гость | Диспетчер |
|---|---|---|
| «Лента» | `/rhumbs/feed` | `/rhumbs/feed` |
| «Добавление» | заблокирован | `/rhumbs/draft` |
| «Плитка» | `/rhumbs` | `/rhumbs` |
| «Вход» / «Выход» | «Вход» — `/rhumbs/login` | «Выход» — выход и переход на «Плитку» |

## Запуск

Нужен запущенный бэкенд: API — http://localhost:3000, S3 (Minio) — http://localhost:9000.

```bash
npm install
npm run generate-api
npm run dev
```

- **Адрес:** http://localhost:5173, открывается «Плитка»
- **Прокси Vite:** `/api` → http://localhost:3000, `/minio` → http://localhost:9000
  (префикс `/minio` убирается)
- **Без бэкенда:** гость видит mock-данные (`src/modules/rhumbsMock.ts`, файлы в
  `public/rhumbs-mock`), у диспетчера mock нет
