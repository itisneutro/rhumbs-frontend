# Румбы ветра — фронтенд

SPA «Румбы ветра»: время полёта Boeing-737 NG Лондон–Париж в зависимости от направления
ветра. React + TypeScript + Vite, React-Bootstrap, Redux Toolkit. Бэкенд — отдельный
репозиторий https://github.com/itisneutro/rhumbs-backend.

## Лабораторные и ветки

| ЛР | Ветка | Что сделано |
|---|---|---|
| ЛР-5 | `rhumbs-spa-lab5` | SPA гостя на mock-данных |
| ЛР-6 | `rhumbs-redux-lab6` | Redux, кодогенерация axios из Swagger, прокси, вход/выход, добавление, удаление, лайки |

## Роли

- гость — без входа;
- диспетчер — вошедший пользователь.

Роль хранится только в Redux: после обновления страницы приложение снова гостевое.

## Страницы

### «Лента»

Маршрут: `/rhumbs/feed` — первый румб, `/rhumbs/feed/:id` — румб с этим id.

- Отображается: видео (сразу, по кругу, без звука), название, описание, роза румбов,
  «Географический» и «Магнитный» азимуты, число лайков.
- Кнопки: «Ещё» / «Свернуть» — раскрыть и свернуть описание; лайк — сердце с числом
  лайков; круглая кнопка со стрелкой (`aria-label="Следующий"`) — следующий румб по кругу.
- Гость: смотрит ленту, лайк неактивен. Диспетчер: ставит и снимает лайк.

### «Добавление»

Маршрут: `/rhumbs/draft`.

- Отображается: заголовок «Добавление румба», превью изображения и превью видео (пока файл
  не выбран — `public/rhumbs-default.jpg` и `public/rhumbs-default.mp4`), поле «Название».
  Когда черновик создан — превью из черновика и ещё поля «Краткое описание»,
  «Географический азимут» (0–359, шаг 1), «Магнитный азимут» (0–359.9, шаг 0.1).
- Кнопки: «Выбрать» на превью изображения и видео (пока черновика нет); «Далее» — создать
  черновик; «Опубликовать» — опубликовать румб и перейти на «Плитку».
- Гость: страница недоступна, переход на «Плитку». Диспетчер: создаёт и публикует румб.

### «Плитка»

Маршрут: `/rhumbs`.

- Отображается: заголовок «Румбы ветра»; фильтр — подпись «Азимут от», слайдер от 0
  до 315 с шагом 45 и значение в градусах; карточки в 2 колонки — изображение с названием
  и розой румбов, «Географический» и «Магнитный» азимуты, число лайков.
- Кнопки: «Найти» — румбы с географическим азимутом не меньше выбранного; клик по карточке
  открывает ленту с этого румба; «Удалить» на карточке.
- Гость: смотрит и фильтрует румбы. Диспетчер: ещё удаляет свои румбы — «Удалить» есть
  только на них.

### «Вход»

Маршрут: `/rhumbs/login`.

- Отображается: заголовок «Вход», поля «Логин» и «Пароль».
- Кнопки: «Войти» — вход и переход на «Плитку»; при ошибке у полей красная рамка.
- Гость: входит и становится диспетчером. Регистрации нет.

### Нижняя панель

На всех четырёх страницах, 4 пункта.

| Пункт | Гость | Диспетчер |
|---|---|---|
| «Лента» | `/rhumbs/feed` | `/rhumbs/feed` |
| «Добавление» | заблокирован | `/rhumbs/draft` |
| «Плитка» | `/rhumbs` | `/rhumbs` |
| «Вход» / «Выход» | «Вход» — `/rhumbs/login` | «Выход» — выход и переход на «Плитку» |

## Запуск

Бэкенд должен быть запущен: API — http://localhost:3000, S3 (Minio) —
http://localhost:9000.

```bash
npm install
npm run generate-api
npm run dev
```

Адрес — http://localhost:5173, открывается «Плитка».

- `npm run generate-api` берёт Swagger бэкенда (http://localhost:3000/api/docs-json) и
  создаёт `src/api/Api.ts` — клиент axios только с методами тега `rhumbs`.
- Прокси Vite (`vite.config.ts`): `/api` → http://localhost:3000, `/minio` →
  http://localhost:9000 (префикс `/minio` убирается).
- Без бэкенда гость видит mock-данные (`src/modules/rhumbsMock.ts`, файлы в
  `public/rhumbs-mock`), у диспетчера mock нет.
