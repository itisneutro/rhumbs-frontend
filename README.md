# Румбы — фронтенд (ЛР-5)

SPA для гостя на React + TypeScript + Vite и React-Bootstrap. Данные берутся из
mock-коллекции `RHUMBS_MOCK` (`src/modules/rhumbsMock.ts`, 6 румбов). Работает без
бэкенда и без S3: запросов к API нет.

## Нижняя панель

Четыре пункта: «Лента», «Добавление», «Плитка», «Вход». Доступны только два:

- «Лента» — лента с первого румба, `/rhumbs/feed/1`;
- «Плитка» — `/rhumbs`.

«Добавление» и «Вход» видны, но не нажимаются: в ЛР-5 этих страниц нет.

## Страница «Плитка» — `/rhumbs`

Фильтр:

- подпись «Азимут от»;
- слайдер `Form.Range` от 0 до 315 с шагом 45, рядом — выбранное значение в градусах,
  по умолчанию 0° (все румбы);
- кнопка «Найти» — показывает румбы с географическим азимутом не меньше выбранного.

Карточка румба:

- изображение `imageUrl`, поверх — название `name` и роза румбов по `geoAzimuth` и
  `magAzimuth`;
- «Географический» — `geoAzimuth` в градусах;
- «Магнитный» — `magAzimuth` в градусах;
- сердце с числом лайков `likesCount`.

Клик по карточке открывает ленту с этого румба.

## Страница «Лента» — `/rhumbs/feed/:id`

- видео `videoUrl` — воспроизводится сразу, по кругу, без звука;
- название `name`;
- описание `description` — свёрнуто до двух строк, «Ещё» раскрывает его, «Свернуть»
  сворачивает;
- роза румбов и азимуты «Географический» (`geoAzimuth`) и «Магнитный» (`magAzimuth`)
  в градусах;
- лайки — сердце и `likesCount`, у гостя кнопка лайка неактивна;
- круглая кнопка со стрелкой вниз (`aria-label="Следующий"`) — следующий по id румб
  из всех, после последнего — первый.

## Изображение и видео по умолчанию

- `public/rhumbs-default.jpg` — в карточке «Плитки», если `imageUrl` равно `null` или
  изображение не загрузилось;
- `public/rhumbs-default.mp4` — в «Ленте», если `videoUrl` равно `null` или видео не
  загрузилось.

Все изображения и видео mock лежат в `public/rhumbs-mock`: приложение работает без
бэкенда, без БД и без S3. У «Северо-восточного» (id 2) `imageUrl` и `videoUrl` равны
`null`, у него показываются файлы по умолчанию.

## Запуск

```bash
npm install
npm run dev
```

Адрес — http://localhost:5173, открывается «Плитка» (`/rhumbs`).
